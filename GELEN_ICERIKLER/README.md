# Dosyaları Buraya Koyun

1. Metinleri `METINLER` klasörüne koyun.
2. Ürün fotoğraflarını `URUN_GORSELLERI` klasörüne koyun.
3. Diğer sayfa fotoğraflarını `SAYFA_GORSELLERI` klasörüne koyun.
4. PDF katalog ve broşürleri `BELGELER` klasörüne koyun.
5. Sonra Codex'e **“Dosyaları koydum”** yazın.

Parola, e-posta şifresi veya API anahtarı koymayın.

Ayrıntılı liste: `docs/icerik-ekleme-rehberi.md`

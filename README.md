# InBody Türkiye — Yerel Web Sitesi

InBody Türkiye için sıfırdan hazırlanmış, yalnızca yerel ortamda çalışan kurumsal web sitesi ilk sürümüdür. Mevcut sitenin kaynak kodu kullanılmamıştır.

## Yerel çalıştırma

Gereksinimler: güncel Node.js ve npm.

```bash
npm install
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini açın.

## Kontroller

```bash
npm run lint
npm run build
```

## İçerik ve görseller

- Yerel içerikler `content` klasöründedir.
- Yerel görseller `public/images` klasöründedir.
- Proje planı, sayfa haritası, ürün ve içerik envanteri `docs` klasöründedir.
- Eksik/onay bekleyen alanlar `docs/eksik-icerikler.md` dosyasında tutulur.

## Kapsam notu

İletişim formu yalnızca ön yüz demosudur ve gerçek e-posta göndermez. Bu proje için yayınlama, hosting, domain, FTP veya canlı site değişikliği yapılmamıştır.
